# Project Description

## Overview
This project is a hands-on Git and Python practice exercise. It covers 
basic Git workflows — initializing a repository, making commits, using 
.gitignore, creating branches, and merging — alongside basic Python 
programming.

## What I Practiced
- Initializing a local Git repository 
( git init )
- Creating and committing files (README, .gitignore, source code)
- Writing Python functions (`add`, `subtract`) in a separate `utils.py` module
- Importing and using functions across files
- Creating a feature branch (`feature/calculator`)
- Merging a feature branch back into `main`
- Managing ignored files with `.gitignore`
- Adding new functions incrementally and committing changes step by step

# Project Title: Git & GitHub Practical Assignment

**My Name:** Sabit Al Juma

## What this project does

This project is a hands-on practical assignment covering basic Git and 
GitHub workflows. It walks through initializing a local repository, 
creating and formatting a README, ignoring unnecessary files, building 
a simple Python calculator with basic error handling, and managing all 
of it through feature branches and merges.

### Skills Practiced
- Initializing a Git repository and making commits
- Writing and improving a README
- Using `.gitignore` to exclude unnecessary files
- Creating Python functions (`add`, `subtract`, `multiply`, `divide`)
- Adding basic error handling (e.g. divide-by-zero protection)
- Creating, working on, and merging feature branches
- Connecting a local repo to GitHub and pushing changes

### Tech Stack
- Python 3.13
- Git / GitHub
